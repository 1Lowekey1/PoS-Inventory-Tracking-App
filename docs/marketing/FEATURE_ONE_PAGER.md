## PopPOS
### The cashier and inventory app for pop-ups, stalls and small cafés
**Free · Works offline · No account needed**

---

### Built for one person behind the counter
| | |
|---|---|
| ⚡ **Fast checkout** | Two taps for an exact-cash sale. Change calculator. Cash, GCash, Maya, card |
| 👥 **Group orders** | "5 Americanos, 3 with syrup" in one step |
| 📋 **To-make queue** | See who's waiting; tap when handed over |
| ↩️ **Undo & void** | Fix mistakes anytime; stock goes back automatically |

### Stock that counts itself
| | |
|---|---|
| 🧾 **Recipes** | Each sale deducts beans, milk, cups, syrup |
| ⚠️ **Live warnings** | "N left" on products; "~1.5 h left at today's pace" |
| 🔄 **Restock, bought or made** | Homemade syrup uses up the sugar; costs follow automatically |
| 🔍 **Full history** | Sales, restocks, waste and counts, every change logged |

### Money you can trust
| | |
|---|---|
| 💰 **Real profit** | Sales − (capital + expenses), the way pop-ups buy stock |
| 📈 **Break-even** | Watch it fill up while you sell |
| 💵 **Cash count** | Expected vs counted, over/short per day |
| 📊 **Reports** | Busiest hours, best sellers, payment split, ingredient usage, compare events, CSV export |

### Works where you work
| | |
|---|---|
| 📶 **Offline** | No signal at the venue? No problem |
| 📱 **Any device** | Phone, tablet, laptop, café mini PC |
| 🖨️ **Printer & cash drawer** | Optional ESC/POS thermal printers, USB or Bluetooth |
| 🔒 **Private** | Data stays on your device; one-tap backups |
