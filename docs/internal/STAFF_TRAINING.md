# Staff Training Guide

Train a helper or barista on PopPOS in about **30 minutes**. Everything happens in **Practice mode**, so nothing they do counts, and stock is put back afterwards.

## Before the session (trainer)

- [ ] Your real menu is set up (or use *Try a sample coffee menu* on a spare device)
- [ ] Settings → **Practice mode** ON
- [ ] Device at the height and spot it'll be at the counter
- [ ] Printer connected, if you use one

## 1. Tour (5 min)

Show the five tabs and say what each is for:
- **Sell**: where you'll spend 95% of the time
- **Orders**: fix or reprint past sales
- **Stock**: what's left
- **Event**: open/close the day, log expenses
- **Reports**: owner stuff, look but don't touch

Point out the yellow **Practice mode** banner: "While this is here, nothing counts."

## 2. Basic sales (10 min)

Have them do each one themselves. Don't take the device.

| Drill | Pass when |
|---|---|
| Sell 1 Iced Latte, exact cash | Charge → Complete without help |
| 2 lattes + 1 matcha, customer pays ₱500 | Taps ₱500, reads the change aloud |
| GCash payment | Picks GCash before Complete |
| Senior/PWD discount | Uses the **Discount** button |
| Name on the order ("Ana") | Name shows in **To make** |
| Hand over the drink | Taps the chip in **To make** |

## 3. Changes and group orders (5 min)

| Drill | Pass when |
|---|---|
| One Americano with syrup | Taps the **+ Syrup** chip under the line |
| Latte with oat milk | Opens the line (or holds the tile) → Oat milk |
| 5 Americanos, 3 with syrup | **Apply to 3 of 5 cups** → syrup |
| Customer comes back for an extra shot | **+ Add-on** → picks the order number |

## 4. Mistakes (5 min)

| Drill | Pass when |
|---|---|
| Rang up the wrong drink, just now | **Undo** on the message |
| Wrong drink, 10 minutes ago | Orders → order → **Void** with a reason |
| Charged cash but they paid GCash | Orders → *Wrong payment method?* |
| Spilled a latte | Stock → Milk/Beans → **Waste** |

Golden rule: **never delete or edit stock to "fix" a sale.** Void the sale, and stock fixes itself.

## 5. Opening and closing (5 min, for helpers who'll do it)

- Open: Event → **Open day** → count and enter the float.
- Restock during the day: Event → **Restock** → Bought (with cost) or Made.
- Close: Event → **Close day** → count cash → type it in → note over/short → **Backup**.

## Finish

- Settings → turn **Practice mode** OFF. Show them the stock went back.
- Settings → **Delete practice orders**.
- Give them the [Quick Start](../../QUICK_START.md) checklist.

## Counter rules (print and stick near the device)

1. Every drink goes through the app, even freebies (use a 100% discount).
2. Mistakes: **Undo** or **Void**. Never fake it with stock edits.
3. Money for supplies comes out of the drawer? Log it as an **Expense** with *Paid from drawer*.
4. Opened a new pack? Log a **Restock**.
5. Something odd? Write the order number down and tell the owner.
